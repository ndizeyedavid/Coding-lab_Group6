# Kenyatta National Hospital Digital Infrastructure

> Group 6 - Coding Lab

This repository contains 3 scripts which are helping in analyzing and processing the hospital sensor simulation using a python data engine. The scripts are here to manage directory setup, file permissions, data analysis and log archiving.

## Project Objective

As a team of DevOps engineers, we are tasked to:
- Secure and manage hospital sensor data
- control access to sensitive log files
- Analyze critical health and facility metrics
- Archive completed logs safely
- Maintain continous system operation

The Python data engine is generating for us:
1. Heart Rate sensor data
2. Temperature sensor data
3. ICU water usage sensor data

## Environment Setup

1. Clone the repository
```bash
git clone https://github.com/ndizeyedavid/Coding-lab_Group6
cd Coding-lab_Group6
```

2. Start the hospital data engine
```bash
python3 hospital_system.py start
```

3.To Stop the Engine
```bash
python3 hospital_system.py stop
```
